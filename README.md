# Klang-Box Raum-Check

Mess-Webseite der Klang-Box: Ein-Knopf-Messung (AirPlay oder zweites Gerät), Aufnahme ohne Filter, Wächter prüft jede Aufnahme, Kino- oder Stereo-Score, Prognose mit Klang-Box und Vergleich mehrerer Anlagen. Alles läuft im Browser, nichts wird hochgeladen.

Diese Seite wird aus dem privaten Klang-Box-Projekt erzeugt (`werkzeuge/raumcheck_seite.py`).
